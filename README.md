## Prérequis

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- `dotnet-ef` CLI (`dotnet tool install --global dotnet-ef --version 8.0.10`)
- Instance locale **MongoDB** sur `mongodb://localhost:27017` (ex. via Docker/Podman : `docker run -d -p 27017:27017 --name mongodb mongo:latest`)
